# sat-esm

This is the [sat](https://www.npmjs.com/package/sat) package but rewritten in ES6 and ESM syntaxes.

All functionality is the same, see the [sat](https://www.npmjs.com/package/sat) package for all documentation.

Note that some types in this package do not match types exported by the [@types/sat](https://www.npmjs.com/package/@types/sat) package, because that package's types _are wrong_.

## Install

Instead of installing `sat`, install `sat-esm`:

```sh
npm i sat-esm
```
